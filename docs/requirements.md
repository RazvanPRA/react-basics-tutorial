# Requirements

As dori o aplicatie cu react in care voi invata toti termenii obligatorii pentru a cunoaste react si a putea sa fac aplicatii in react.

NU vreau sa generezi codul din start, ci sa ma ghidezi pas cu pas pentru fiecare concept, sa-l putem intelege si sa-l aplicam.

De la inceput as vrea sa generezi copilot-intructions.md pentru .github si CODEX.md care se vor sincroniza automat cu scripturi (sh)

Aplicatia curenta este folosita de catre developer incepatori in web, care cunosc alte limbaje de programare cum ar fi Python, Java sau C#, dar nu au experienta cu JavaScript si React
